1、遍历整个列表，使用`for`循环，例如
	```colors=['red','blue','yellow']
	for color in colors:
		print(color)
	>>>red
	>>>blue
	>>>yellow	```
对于`for`循环的临时变量可以指定任何名称
2、在`for`循环中可以执行多种操作，例如`title()`方法等，不再一一赘述。
3、`for`循环严格限制缩进，不恰当的缩进往往改变原本想要的结果。`for`循环后一定有冒号，否则不执行且报错
4、使用函数`range()`来生成一系列数字，例如
	```for value in range(1,5):
		print(value)
	>>>1
	>>>2
	>>>3
	>>>4	```
需要注意的是，此函数左闭右开，生成左侧第一个数字但不会生成右侧最后一个数字。
同时，该函数还可以指定生成的步长，例如
	```for number in range(2,11,2)
		print(number)
	>>>2
	>>>4
	>>>6
	>>>8
	>>>10	```
上例的意思是，从2开始，每隔两个数生成一次，到10停，即生成1-10的偶数
5、使用函数`list()`创建数字列表，例如
	```numbers=list(range(1,6))
	print(numbers)
	>>>[1,2,3,4,5]	```
6、几个专门统计数字列表的函数，`max()`、`min()`、`sum()`，用法自行体会
7、列表解析简化代码行数，将循环和创建新元素的代码放在一行，例如
	```squares=[value**2 for value in range(1,11)]
	print(squares)
	>>>[1,4,6,16,25,36,49,64,81,100]	```
使用这种语法，先确定一个列表名，方括号内先写生成列表值的表达式，再写一个循环，给表达式供值。需要注意的是，这里的循环后面不需要冒号。
8、列表切片可以使用列表的任一部分值，但是和函数`range()`一样，左闭右开，例如
	```colors=['red','blue','yellow','black','white']
	print(colors[0:3])
	>>>['red','blue',yellow']	```
如果没有指定第一个索引，默认从头开始，如果没有指定最后一个索引，默认读到最后。
还可以用负数切片，返回到末尾的切片，例如
	```colors=['red','blue','yellow','black','white']
	print(colors[-3:])
	>>>['yellow','black','white']	```
9、对列表切片可以遍历其中的元素，切片的本质就是列表，和上述遍历列表用一样的方法，只不过是切片
10、想要复制列表可以同时省略初始索引和末尾索引，即`[:]`，即可复制生成新的列表，和直接进行列表之间的赋值不同，这种方法是生成一个全新列表，和父列表没有关系。
11、不可变的列表称为元组，与普通列表不同的是，元组用圆括号括起来，例如
	```dimensions=(200,50)
	print(dimensions[0])
	print(dimensions[1])
	>>>200
	>>>50	```
元组不能修改其中的元素值，如果强行修改系统会报错，但是可以重新定义整个元组。同样，可以用循环遍历元组中的各种值。
